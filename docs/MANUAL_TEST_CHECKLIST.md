## M-1 — Google OAuth 로그인, 로그아웃 및 세션 유지
- **Refs:** `RQ-3`, `DC-3`
- **사전 조건:** 유효한 Google OAuth 자격 증명과 `BOOTSTRAP_ADMIN_EMAIL` 설정 완료.
- **절차:**
  1. 시크릿 창에서 앱 루트(`/`)에 접속한다.
  2. 로그인 화면이 표시되는지 확인하고 `Google로 로그인`을 클릭한다.
  3. 허용된 관리자 Google 계정으로 로그인한다.
  4. 브라우저를 새로고침(`F5`)한 뒤 세션이 유지되는지 확인한다.
  5. `로그아웃` 버튼을 클릭한 뒤 다시 `/`에 접속한다.
- **Pass 기준:**
  - 로그인 후 `/` 갤러리 화면으로 정상 이동하고 `r2album_session` 쿠키에 `HttpOnly` 속성이 설정되어 있다.
  - 새로고침 후에도 재로그인 없이 세션이 유지된다.
  - 로그아웃 후 즉시 세션이 무효화되고 로그인 화면으로 돌아간다.
- **Fail 기준:** 로그인 루프 발생, 쿠키가 `document.cookie`에서 읽힘, 로그아웃 후에도 API 접근 가능.

## M-2 — RBAC 및 비인가 접근 차단
- **Refs:** `RQ-3`, `RQ-4`, `RQ-11`, `DC-3`
- **사전 조건:** 허용 목록에 없는 이메일 1개, `viewer` 권한 이메일 1개, `admin` 권한 이메일 1개 준비.
- **절차:**
  1. 미로그인 상태에서 브라우저/curl로 `GET /api/images`, `GET /api/filters`, `GET /api/admin/stats`를 호출한다.
  2. 허용 목록에 없는 Google 계정으로 로그인을 시도한다.
  3. `viewer` 계정으로 로그인한 뒤 UI에 `관리자` 메뉴가 보이지 않는지 확인하고, 주소창에 `/admin`을 직접 입력한다.
  4. `viewer` 세션 쿠키로 `POST /api/admin/albums` 또는 `DELETE /api/admin/images/<id>`를 호출한다.
- **Pass 기준:**
  - 미로그인 API 호출은 모두 `401 Unauthorized` 반환.
  - 비허용 계정은 로그인 거부 화면(`/login?error=unauthorized`)으로 안내되며 세션 쿠키가 발급되지 않음.
  - `viewer`는 `/admin` 접근 시 `/`로 리다이렉트되고, 모든 `/api/admin/*` 호출에서 `403 Forbidden`을 받는다.
- **Fail 기준:** 비허용 계정 로그인 성공 또는 `viewer`가 관리자 데이터 조회/변경을 수행함.

## M-3 — Private R2 보안 및 브라우저 캐시 검증
- **Refs:** `RQ-4`, `DC-4`
- **사전 조건:** 최소 1장 이상의 이미지가 업로드된 상태.
- **절차:**
  1. 로그인된 브라우저의 개발자 도구(Network 탭)에서 썸네일 요청(`/api/media/thumb/<id>`)의 응답 헤더를 확인한다.
  2. 해당 URL을 복사해 시크릿 창(미로그인 상태)에서 직접 열어본다.
  3. Cloudflare 대시보드에서 R2 버킷 Public Access(r2.dev / 커스텀 퍼블릭 도메인)가 비활성 상태인지 확인한다.
  4. 로그인 상태에서 페이지를 새로고침하고 썸네일이 브라우저 캐시(또는 `304`)로 재사용되는지 확인한다.
- **Pass 기준:**
  - 인증 응답에 `Content-Type: image/webp`, `Cache-Control: private, max-age=31536000, immutable`이 포함된다.
  - 미로그인 시크릿 창에서 동일 URL 요청 시 `401`이 반환되고 이미지가 노출되지 않는다.
  - R2 버킷에 퍼블릭 접근 경로가 없다.
- **Fail 기준:** 미인증 상태에서 이미지 다운로드 가능 또는 `Cache-Control` 누락으로 매번 원본 재전송.

## M-4 — 관리자 다중 업로드: EXIF 촬영일 추출, 회전 보정 & WebP 용량 절감
- **Refs:** `RQ-5`, `RQ-6`, `RQ-11`, `DC-2`, `DC-5`, `DC-6`
- **사전 조건:** `admin` 로그인 상태. EXIF 촬영일·세로 회전(Orientation 6 등)이 포함된 스마트폰 JPEG 사진 5장 이상 + EXIF가 없는 PNG/WebP 2장 준비.
- **절차:**
  1. `/admin`의 업로더에 파일 7장을 한 번에 드래그 앤 드롭한다.
  2. 업로드 진행률과 파일별 원본 크기 대비 변환 후 크기 표시를 확인한다.
  3. 업로드 완료 후 갤러리(`/`)로 이동해 이미지 회전 상태와 정렬 순서를 확인한다.
  4. `/admin`의 저장 용량 통계가 증가한 바이트와 일치하는지 확인한다.
- **Pass 기준:**
  - 세로 사진이 눕거나 뒤집히지 않고 올바른 방향으로 저장/표시된다.
  - EXIF 촬영일이 있는 사진은 촬영일 최신순으로, EXIF가 없는 사진은 업로드 시각 기준으로 정렬된다.
  - 3~5MB 스마트폰 사진이 표시용+썸네일 합산 약 150~600KB 수준(WebP)으로 크게 절감되어 저장된다.
- **Fail 기준:** 회전 깨짐, EXIF 촬영일 무시, 원본 그대로(수 MB) 업로드, 진행률 멈춤.

## M-5 — 앨범 · 태그 · 캡션 관리 및 이미지 삭제 정합성
- **Refs:** `RQ-7`, `RQ-11`
- **사전 조건:** `admin` 로그인 상태, 이미지 5장 이상 존재.
- **절차:**
  1. `/admin`에서 새 앨범(예: `제주 여행`)을 생성한다.
  2. 특정 이미지에 앨범 `제주 여행`, 태그 `바다, 가족`, 캡션 `협재 해변`을 저장한다.
  3. 갤러리(`/`)에서 앨범 필터(`제주 여행`)와 태그 필터(`바다`)를 각각 적용하고 조합해 본다.
  4. `/admin`에서 이미지 1장을 삭제(확인 모달 승인)한 뒤, 갤러리 목록과 해당 `/api/media/display/<id>` 접근 및 R2 버킷 객체를 확인한다.
- **Pass 기준:**
  - 필터별 결과와 카운트가 정확히 일치하며 필터 해제 시 전체 목록으로 복귀한다.
  - 삭제 전 확인 모달이 표시되고, 삭제 후 D1 목록과 R2 객체(표시용 + 썸네일 2개 모두)가 사라져 `/api/media/*` 요청 시 `404`를 반환한다.
- **Fail 기준:** 필터 불일치, 확인 없이 즉시 삭제, D1은 지워졌으나 R2에 고아 파일 잔존.

## M-6 — 갤러리 Virtual Scroll & 구간별 Lazy Fetch
- **Refs:** `RQ-8`, `DC-7`
- **사전 조건:** 최소 120장 이상(3청크 이상)의 이미지가 등록된 환경(로컬 시드 데이터 가능).
- **절차:**
  1. 개발자 도구 Network 탭을 열고 `/`에 진입한다.
  2. 초기 로드 시 전체 120장이 아닌 첫 구간 청크(`offset=0&limit=40` 등)만 요청되는지 확인한다.
  3. 스크롤바를 중간·하단으로 빠르게 이동한 뒤 다시 상단으로 올려본다.
  4. Elements 탭에서 DOM에 마운트된 썸네일 카드 개수를 확인한다.
- **Pass 기준:**
  - 스크롤 이동 시 필요한 구간의 `offset/limit` 요청만 발생한다.
  - 이미 방문한 구간으로 다시 스크롤할 때 동일 청크를 중복 fetch하지 않는다(메모리 캐시 히트).
  - 전체 120장 이상이어도 DOM에는 현재 뷰포트+overscan 범위 카드만 유지된다.
- **Fail 기준:** 초기 진입 시 전체 목록 일괄 로드, 스크롤할 때마다 이미 받은 청크 재요청, 스크롤 튐/빈 화면 고착.

## M-7 — 라이트박스 상세 보기
- **Refs:** `RQ-9`
- **사전 조건:** 캡션·앨범·태그가 있는 이미지 포함 3장 이상 등록.
- **절차:**
  1. 갤러리에서 임의의 썸네일을 클릭한다.
  2. 고화질 표시용 WebP, 촬영일, 앨범, 태그, 캡션 표시를 확인한다.
  3. 키보드 `ArrowRight`, `ArrowLeft`로 이전/다음 이동하고 `Escape`로 닫는다.
  4. 모바일 뷰포트에서 좌우 스와이프 동작을 확인한다.
- **Pass 기준:** 이미지 비율 왜곡 없이 선명하게 표시되고 메타데이터 및 키보드/스와이프/닫기가 모두 정상 동작한다.
- **Fail 기준:** 썸네일 저화질이 확대 표시됨, 첫/마지막 경계에서 오류 발생, 모달 닫힌 뒤 배경 스크롤 잠금 미해제.

## M-8 — 전체화면 액자 롤링 모드 (Photo Frame)
- **Refs:** `RQ-10`, `DC-8`
- **사전 조건:** 최소 5장 이상 이미지가 있으며 특정 앨범에 3장 이상 포함.
- **절차:**
  1. 전체 갤러리에서 `액자 모드` 버튼을 클릭한다.
  2. 전체화면 진입 후 지정 간격(예: 3초)마다 다음 이미지가 **깜빡임(흰/검은 화면 끊김) 없이 부드러운 Fade**로 전환되는지 확인한다.
  3. `랜덤` 모드로 전환하고 전체 장수만큼 순환할 때 한 바퀴 안에 같은 사진이 연속/중복 노출되지 않는지 확인한다.
  4. 전환 간격 변경(`3s` → `5s`), `일시정지`/`재개`, 전환 효과(`Fade` / `Fade + Ken Burns`) 토글, 3초 무조작 시 HUD 자동 숨김을 확인한다.
  5. `ESC`로 종료한 뒤 특정 앨범 필터를 선택한 상태에서 다시 `액자 모드`를 실행한다.
- **Pass 기준:**
  - 프리로드 후 부드러운 크로스페이드로 전환되며, 랜덤 셔플이 한 사이클 내 중복 없이 순환한다.
  - 필터 선택 상태에서 진입 시 해당 앨범/태그 범위의 사진만 롤링된다.
  - 종료 시 전체화면이 해제되고 타이머가 완전히 멈춘다(백그라운드 이미지 요청 없음).
- **Fail 기준:** 전환 시 이미지가 로딩되며 뚝뚝 끊김, 필터 무시, 종료 후에도 백그라운드 fetch 지속.

## M-9 — 허용 사용자 관리 (`DC-3` D1 UI 방식 확정 시)
- **Refs:** `RQ-3`, `RQ-11`, `DC-3`
- **사전 조건:** `admin` 로그인 상태.
- **절차:**
  1. `/admin` 사용자 관리에서 테스트 이메일을 `viewer`로 추가한다.
  2. 해당 이메일로 시크릿 창에서 Google 로그인하여 갤러리 열람 가능, `/admin` 차단 여부를 확인한다.
  3. 다시 `admin` 화면에서 해당 이메일을 삭제한 뒤, 해당 사용자가 재로그인할 수 없는지 확인한다.
  4. `BOOTSTRAP_ADMIN_EMAIL` 본인 삭제를 시도한다.
- **Pass 기준:** 추가/삭제가 재배포 없이 즉시 반영되며, `BOOTSTRAP_ADMIN_EMAIL` 자기 삭제는 차단된다.
- **Fail 기준:** 삭제된 사용자가 계속 로그인 성공하거나 부트스트랩 관리자가 삭제되어 잠금 발생.

## M-10 — Cloudflare Workers 프로덕션 배포 검증
- **Refs:** `RQ-1`, `DC-1`, `DC-10`
- **사전 조건:** Cloudflare R2 버킷, D1 프로덕션 DB 마이그레이션, Workers Secrets 및 Google OAuth 프로덕션 Redirect URI 등록 완료.
- **절차:**
  1. `pnpm deploy`로 Cloudflare Workers 프로덕션에 배포한다.
  2. 프로덕션 HTTPS 도메인에서 `M-1` ~ `M-9`의 핵심 경로(로그인 → 업로드 → 갤러리 조회 → 액자 모드 → 삭제)를 1회 완주한다.
  3. 브라우저 콘솔과 Cloudflare Workers 로그에 미처리 예외가 없는지 확인한다.
- **Pass 기준:** 단일 프로덕션 도메인에서 CORS 오류·쿠키 누락·500 에러 없이 모든 핵심 시나리오가 통과한다.
- **Fail 기준:** OAuth 리다이렉트 URI 불일치, R2/D1 바인딩 오류, 정적 SPA 새로고침 시 `/admin` 404 발생.

## M-11 — Google OAuth 가입 신청 및 관리자 승인/거절 플로우
- **Refs:** `RQ-12`, `DC-11`
- **사전 조건:** 미등록 Google 테스트 계정 2개(승인용 1, 거절용 1) 및 `admin` 계정 준비.
- **절차:**
  1. 시크릿 창에서 미등록 Google 계정 A로 `Google 계정으로 로그인 / 가입 신청`을 클릭한다.
  2. `/login?status=pending` 화면에 승인 대기 메시지가 표시되고, 세션 쿠키가 발급되지 않았는지 확인한다.
  3. `/admin` 사용자 관리에서 계정 A가 `승인 대기` 목록에 이름·이메일과 함께 표시되는지 확인하고 `Viewer로 승인`을 클릭한다.
  4. 시크릿 창에서 계정 A로 다시 Google 로그인을 시도해 갤러리 열람이 가능한지 확인한다.
  5. 미등록 Google 계정 B로 가입 신청 후 `/admin`에서 `거절` 처리하고, 계정 B 재로그인 시 `/login?error=rejected` 안내 및 세션 미발급을 확인한다.
- **Pass 기준:**
  - 미등록 계정은 자동 `pending` 등록되며 승인 전까지 어떤 API/이미지에도 접근 불가(`401`).
  - 관리자 승인 직후 재로그인으로 정상 접근 가능하며, 거절된 계정은 접근 차단된다.
- **Fail 기준:** `pending` 또는 `rejected` 계정에 세션 쿠키 발급, 대기 목록 미표시, 승인 후에도 로그인 거부.

## M-12 — 관리자 대량 정리, 촬영일 보정, 백그라운드 업로드 & 9.5 GB 하드캡
- **Refs:** `RQ-11`, `RQ-14`, `RQ-15`, `DC-12`, `DC-13`, `DC-15`
- **사전 조건:** `admin` 로그인 상태. EXIF 없는 사진 포함 50장 이상 존재.
- **절차:**
  1. `/admin` → `사진 업로드`에서 여러 장을 선택해 업로드를 시작한 뒤, 업로드 도중 `이미지 관리` 탭 및 `/` 갤러리로 이동한다.
  2. 상단 헤더에 `업로드 N/M` 배지가 실시간 갱신되는지, 새로고침 시도 시 브라우저 이탈 경고가 뜨는지 확인하고, 다시 `사진 업로드` 탭으로 돌아온다.
  3. `/admin` → `이미지 관리`에서 페이지당 표시 개수를 `40장씩` → `100장씩`으로 변경한다.
  4. `촬영일 없음만 보기` 필터를 선택해 EXIF 누락 사진만 모아보고, 여러 장을 체크한 뒤 상단 일괄 작업 바에서 **일괄 촬영일 적용 · 일괄 앨범 이동 · 일괄 태그 추가 · 태그 칩 원클릭 제거**를 차례로 실행한다.
  5. 상단 R2 스토리지 게이지에 `9.5 GB` 보호 한도 안내가 표시되는지 확인한다.
- **Pass 기준:**
  - 탭/갤러리 이동 중에도 업로드가 중단되지 않고 완료되며, 상단 배지와 업로드 큐 상태가 일치한다.
  - 일괄 촬영일 적용 후 해당 사진들은 `촬영일 없음만 보기` 목록에서 자동으로 빠지고, 앨범/태그 일괄 변경이 즉시 반영된다.
- **Fail 기준:** 탭 전환 시 업로드 큐 소실, 100건 이상 일괄 작업 시 D1 오류 발생, 일괄 촬영일 적용 후에도 EXIF 없음 필터에 잔존.

## M-13 — 갤러리 연도별 Virtual Scroll, 모바일 1줄 Sticky 연도 바 & 연도별 액자 모드
- **Refs:** `RQ-8`, `RQ-10`, `RQ-13`, `DC-14`
- **사전 조건:** 최소 2개 이상의 서로 다른 연도(예: `2026년`, `2025년`)에 촬영된 사진 등록.
- **절차:**
  1. `/` 갤러리(데스크톱 및 모바일 뷰포트)에서 사진들이 연도별 섹션 헤더(`2026년 · N장`, `2025년 · N장`)로 구분되어 표시되는지 확인한다.
  2. 아래로 스크롤하면서 상단 네비게이션 아래에 1줄 슬림 Sticky 연도 바가 따라다니며 현재 보고 있는 연도 칩과 `{YYYY}년 액자` 버튼이 자동 갱신되는지 확인한다.
  3. Sticky 연도 바에서 다른 연도 칩을 탭해 해당 연도 섹션으로 바로 점프하는지 확인한다.
  4. Sticky 바(또는 연도 헤더)의 `2025년 액자` 버튼과 상단 필터바의 `연도 선택` → `액자 모드` 각각으로 진입해 해당 연도 사진만 롤링되는지 확인한다.
- **Pass 기준:**
  - 모바일에서도 Sticky 연도 바가 줄바꿈 없이 1줄 슬림 높이를 유지하며, 연도 칩 가로 스와이프와 섹션 점프가 부드럽게 동작한다.
  - 연도별 액자 모드 진입 시 선택한 연도(및 활성 앨범/태그 조합)의 사진만 롤링된다.
- **Fail 기준:** 모바일에서 Sticky 바가 2~3줄로 겹쳐 갤러리를 가림, 연도 점프 시 빈 화면 고착, 다른 연도 사진이 섞여 재생됨.
